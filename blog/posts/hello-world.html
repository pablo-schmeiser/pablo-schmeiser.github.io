Hello World: My First Post

August 8, 2026  •  3 min read

Welcome to my very first blog post! Setting up a static site using Material Design for Bootstrap has been an exciting journey. In this post, I want to talk a little bit about why I chose this stack and what you can expect from this blog in the future.

Why a Static Site?

Static sites are incredibly fast, secure, and easy to host. By leveraging simple HTML, CSS, and JavaScript, there are no databases to maintain or complex server setups to manage. Hosting it on platforms like GitHub Pages is essentially free and extremely reliable.

The Magic of MDBootstrap

I wanted a modern, premium look for my resume and blog. By combining MDBootstrap with custom Glassmorphism CSS, I was able to achieve this beautiful dark theme aesthetic quickly. The built-in components and animations save hours of development time.

What's Next?

I'll be posting regularly about:

  • Web development tips and tricks
  • UI/UX design principles
  • My journey in software engineering
